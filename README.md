# Ghareeb Aljurdabi portfolio

A personal portfolio built with plain HTML, CSS and JavaScript. Open index.html in a browser to view it. Website content comes from content.md.

- index.html is the home page; projects/ contains the Reboot01 project page.
- css/ contains styles by section, responsive layouts and reduced-motion rules.
- js/ contains one file per interactive feature; images/ contains the SVG favicon.
- 404.html is the missing-page screen. Add cv.pdf to the project root for the CV links.
